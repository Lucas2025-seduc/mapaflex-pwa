Gerenciador Seguro de Licenças MapaFlex

Este arquivo é um atalho portátil para o painel administrativo. Ele não guarda senha, chave do banco, chave de API nem códigos completos de licença.
🔒 Os códigos são gerados no servidor com 128 bits de aleatoriedade, aparecem completos apenas no momento da geração e ficam armazenados no banco somente como hash SHA-256.
