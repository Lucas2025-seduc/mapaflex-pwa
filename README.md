# MapaFlex PWA

Aplicativo progressivo para criação e estudo de mapas mentais/conceituais, com persistência local via IndexedDB e instalação como PWA.

## Estado atual

Estrutura inicial criada para publicação no Vercel.

## Recursos desta base

- PWA instalável
- Service Worker para funcionamento offline básico
- IndexedDB para armazenamento local
- Interface inicial para criação de mapas e balões
- Exportação/importação local em JSON
- Estrutura preparada para evolução com anexos, áudio e integrações de IA

## Publicação

Projeto estático compatível com Vercel. Basta importar este repositório e publicar a branch `main`.
